Yu Wang, PhD

Research Scientist · Medical College of Wisconsin

I am a biostatistician who builds statistical methods and fast, open-source software for genomic data. My recent work covers rare-variant association testing that uses local ancestry, detection of mosaic chromosomal alterations from whole-genome sequencing, study design for single-cell RNA-seq, and random forests for composite survival endpoints. Most of my tools pair a user-facing R interface with a C backend.

Research

Statistical genetics

Rare-variant aggregate tests informed by local ancestry in admixed populations; gene- and pathway-level tests for survival outcomes; detection of mosaic chromosomal alterations from WGS.

Single-cell & sequencing methods

Read-level simulation for single-cell RNA-seq study design, and efficient processing of FastQ/BAM data down to cell × UMI and exon-level summaries.

Survival analysis & machine learning

Random forests for composite endpoints, and Bayesian monitoring rules for toxicity in multi-cohort phase II clinical trials.

Software

LANTERN

R · C

Rare-variant aggregate association tests that use local ancestry tracts; supports up to five ancestries. Submitted to Bioconductor.

Code Docs Preprint

Rforce

R · C/C++

Random forests for composite endpoints of non-fatal and terminal events, built on generalized estimating equations (GEE). Won the 2024 ASA Student Paper Competition Award.

Code Docs Paper

FastQDesign

R · C/C++

Study design for single-cell RNA-seq, based on realistic simulation at the FastQ read level.

Code Docs Paper

aSPUS

R · C

Adaptive sum of powered score tests for gene and pathway association with survival traits, using permutation-based inference.

Code Docs Preprint

fastF

C

Command-line tool to sample, filter and summarize single-cell FastQ/BAM data, down to a UMI count matrix. Companion to FastQDesign.

Code Paper

exonBlocks

C · R

Maps cell barcode + UMI read blocks to the exons they overlap.

Code

MoSAIC

C · in development

Hidden Markov model for detecting mosaic chromosomal alterations from WGS. It combines read depth, phased B-allele frequency and switch error rate.
